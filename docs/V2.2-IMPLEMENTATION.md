# 2.2 implementation plan

This is development work based on main after PR #77. Version 2.2 is planned.
The goal is retopology and optimization that preserve the requested appearance
and scene data. Each change should reuse an existing script and add a regression
for a demonstrated failure.

## First increment

The balanced optimizer dissolved authored seams, sharp edges and UV boundaries
on a two-quad planar fixture. Limited dissolve now uses MATERIAL, SEAM, SHARP,
UV and NORMAL delimiters. A plain coplanar edge still dissolves. The existing
deformation guard is exercised with an armature-modified mesh.

This covers the dissolve operation. Merge-by-distance, decimation previews,
baking, deformation and rendered appearance require their own checks.

## Next increments

| Case | Work | Acceptance evidence |
| --- | --- | --- |
| Mechanical part | Exercise bevelled edges and material boundaries through the existing optimizer. Diagnose losses before changing algorithms. | Evaluated triangle counts, unchanged source, close-up renders under identical lighting, preserved material assignments and intended edge shading. |
| Stylized prop | Exercise the existing silhouette comparison and optimization on a prop with an opening, a concavity and thin details. | Matched front, side and three-quarter renders. Visual inspection of the opening and details, alongside measured counts. The convex-hull proxy has explicit limits for these features. |
| Deforming mesh | Exercise guided retopology on an unrigged source copy. Then validate authored skinning at rest, intermediate and extreme poses. | Source and checkpoint preserved, UV and material checks, pose captures with measured deformation defects. Existing shape-key and deformation guards continue to apply during topology edits. |

Before each case, record the brief, viewing distance, budget and acceptable
deviation. Use disposable fixtures first. Store measurements and actual captures
with the source revision. Add rendering or pose analysis only where it answers a
specific acceptance question.

## Completion

The three cases must have reviewed evidence and explicit remaining limits.
Run the regression suite on the final source and verify the distributable ZIP.
The release decision follows review of those results.
