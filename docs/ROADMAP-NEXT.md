# Roadmap after 1.0

This historical plan led to [v2.0.0](release-notes-2.0.md), published on
2026-11-13. See [current evidence and open work](V2-EVIDENCE.md) before
using any historical milestone as a compatibility claim.

| Milestone | Original focus |
| --- | --- |
| 1.0.1 | Installation, error messages, scene preservation and regressions. |
| 1.1 | Joint contact, topology diagnostics, silhouette and checkpoint comparison. |
| 1.2 | Design questions, UV checks, GLB round trips and target-editor inspection. |
| 1.3 | Agent autonomy, bounded retries and measured usage. |
| 1.4 | Visual correction, component fit, scorecards and export protection. |
| 1.5–1.9 | PBR, game-ready delivery, specialist execution, benchmarks and evidence. |
| 2.0 | Integrated workflows and recoverable edits. |

The [milestone ledger](V1.5-V2.0-MILESTONES.md) records implementation and validation separately.
